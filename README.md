# 税务数据处理系统

自动化处理发票数据，生成应收/应付数据、实收实付数据和凭证分录。

## 功能特性

### 应收应付
- 自动拆分发票数据（专票、普票、进项）
- 按单位名称汇总生成应收/应付数据
- 生成符合模板的凭证分录（73字段）
- 自动匹配客户/供应商编码

### 实收实付（银行流水处理）
- 银行流水按月按对方单位汇总（转入/转出/其他支出）
- 转入凭证：借102银行存款 / 贷122应收账款
- 转出凭证：借126预付账款 / 贷102银行存款
- 其他支出单独统计（银行手续费、工资等）

### 档案管理
- 客户档案维护（增删改查、导入导出）
- 供应商档案维护（增删改查、导入导出）
- 批量导入支持 Excel/CSV

## 使用方式

### Web服务

```bash
./start.sh start    # 启动服务
./start.sh stop     # 停止服务
./start.sh restart  # 重启服务
./start.sh status   # 查看状态
./start.sh log      # 查看日志
```

访问 http://127.0.0.1:15090（默认端口15090）

- 首页：选择"应收应付"或"实收实付" Tab，上传文件，处理后下载结果
- 档案管理：维护客户/供应商档案

### 命令行

```bash
# 应收应付处理
python run_accounts_pipeline.py 3
python run_accounts_pipeline.py 3 --invoice-file data.xlsx --output-dir output

# 实收实付处理
python run_actual_pipeline.py 4 --invoice-file Docs/实收实付/4月预付.xlsx
```

## 数据处理流程

### 应收应付

```
原始发票文件 (2026年发票统计.xlsx)
    │
    ▼
┌─────────────────────────────────────────┐
│  1. 拆分发票数据                          │
│     - 专票 → 专票sheet                   │
│     - 普票 → 普票sheet                   │
│     - 进项 → 进项sheet                   │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│  2. 生成应收/应付数据                      │
│     - 专票+普票 → 应收数据sheet           │
│     - 进项 → 应付数据sheet                │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│  3. 生成凭证分录                         │
│     每行应收数据拆分为3条分录:            │
│     - 借: 应收账款 (122, 单票合计)        │
│     - 贷: 商品销售收入 (501, 金额)        │
│     - 贷: 销项税 (2210102, 税额)          │
└─────────────────────────────────────────┘
```

### 实收实付（银行流水）

```
银行流水文件 (4月预付.xlsx)
    │
    ▼
┌─────────────────────────────────────────┐
│  1. 拆分银行流水                         │
│     按月按对方单位汇总                    │
│     - 转入汇总 sheet                     │
│     - 转出汇总 sheet                     │
│     - 其他支出 sheet（手续费/工资）       │
└─────────────────────────────────────────┘
    │
    ├── ▼ 转入凭证（收回应收账款）
    │   借: 102 银行存款（汇总1行）
    │   贷: 122 应收账款（每单位1行）
    │
    └── ▼ 转出凭证（预付账款）
        借: 126 预付账款（每单位1行）
        贷: 102 银行存款（汇总1行）
```

## 输出文件

### 应收应付

| 文件 | 说明 |
|------|------|
| `{月份}月发票明细.xlsx` | 发票明细 + 应收数据 + 应付数据 |
| `{月份}月应收凭证分录.xlsx` | 凭证分录（73字段） |
| `{月份}月未匹配客户.xlsx` | 未匹配客户列表 |

### 实收实付

| 文件 | 说明 |
|------|------|
| `{月份}月实收实付明细.xlsx` | 转入汇总 + 转出汇总 + 其他支出 |
| `{月份}月转入凭证分录.xlsx` | 收回应收账款凭证 |
| `{月份}月转出凭证分录.xlsx` | 预付账款凭证 |
| `{月份}月未匹配客户.xlsx` | 未匹配客户列表 |
| `{月份}月未匹配供应商.xlsx` | 未匹配供应商列表 |

## 数据库

SQLite数据库 `data.db`，包含以下表：

- `customers` - 客户档案
- `suppliers` - 供应商档案

## 凭证分录模板

符合标准凭证模板，共73个字段：
- 凭证基本信息（会计期间、凭证编号、日期等）
- 分录信息（摘要、科目、金额）
- 辅助核算（客户、供应商、部门、项目等）
- 控制字段（可修改标志、核销标志等）
